# SANAD Website

ملفات موقع الشروط والخصوصية لبوت SANAD، جاهزة للنشر على GitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية
- `terms.html` شروط الاستخدام
- `privacy.html` سياسة الخصوصية
- `assets/style.css` التصميم
- `assets/site.js` سنة حقوق النشر

## قبل النشر
1. راجع شروط الاستخدام وسياسة الخصوصية وطابقهما مع سلوك البوت الفعلي وقواعد البيانات.
2. أضف رابط سيرفر الدعم أو وسيلة تواصل حقيقية في `index.html`.
3. راجع أنواع البيانات ومدد الاحتفاظ ومزودي الاستضافة في `privacy.html`. لا تنشر أي ادعاء لا يطابق التنفيذ.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً باسم `sanad-website`.
2. ارفع جميع الملفات مع الحفاظ على مجلد `assets`.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages. استخدم:
   - `https://USERNAME.github.io/sanad-website/`
   - `https://USERNAME.github.io/sanad-website/terms.html`
   - `https://USERNAME.github.io/sanad-website/privacy.html`

استبدل `USERNAME` باسم حساب GitHub الحقيقي. الروابط أعلاه أمثلة وليست منشورة بعد.
